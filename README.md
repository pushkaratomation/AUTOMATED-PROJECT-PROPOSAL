# 🚀 Automated AI Project Proposal Generator

An automated workflow built with **Make.com**, **Google Gemini AI**, **Google Sheets**, and **Google Docs** that ingests client requirements payloads and dynamically synthesizes customized, professional project proposals in minutes.

---

## 📌 Business Overview

Writing customized project proposals for every inbound client lead is time-consuming. This workflow automates the document drafting phase:
1. Listens for client requirement submissions via **Google Sheets / Webhooks**.
2. Synthesizes project scopes, milestone timelines, and cost breakdowns using **Google Gemini AI**.
3. Dynamically injects structured content into a **Google Docs template**.
4. Exports the formatted proposal to **Google Drive** for client delivery.
